# ALX Interview — Algorithms & Problem Solving

A collection of algorithmic problem-solving exercises completed as part of the **ALX Software Engineering Programme**. The repository focuses on applying programming fundamentals to structured coding challenges, including array manipulation, validation, optimization, and API interaction.

## Exercises

| Directory | Topic |
| --- | --- |
| [`0x04-utf8_validation`](./0x04-utf8_validation) | Validate whether a sequence of integers represents valid UTF-8 encoding. |
| [`0x06-starwars_api`](./0x06-starwars_api) | Retrieve and display information from the Star Wars API. |
| [`0x07-rotate_2d_matrix`](./0x07-rotate_2d_matrix) | Rotate a square 2D matrix in place. |
| [`0x08-making_change`](./0x08-making_change) | Solve a coin-change problem using algorithmic reasoning. |
| [`0x09-island_perimeter`](./0x09-island_perimeter) | Calculate the perimeter of an island represented by a grid. |
| [`0x0A-primegame`](./0x0A-primegame) | Apply prime-number reasoning to a two-player game. |

## Skills Practiced

- Algorithm design and problem solving
- Arrays, matrices, and grid traversal
- Input validation and edge-case handling
- Number theory and optimization problems
- Working with an external API

## Repository Structure

Each folder corresponds to an ALX interview-style exercise and contains its implementation and any accompanying exercise files.

## Context

A collection of algorithmic challenges completed during the ALX Software Engineering Programme, covering problem-solving, data structures, algorithm design, and computational efficiency.
